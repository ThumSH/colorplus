# 🎨 ColorPlus Printing Website

### Modern Corporate Website for a Screen Printing Company

ColorPlus is a modern business website developed for a screen-printing company to present its services, capabilities, brand identity, and company information in a professional digital format.

The website was designed to give the business a stronger online presence while making it easier for potential customers to understand the services offered.

---

## 🎯 Business Goal

The main objective of the project was to create a professional online presence for the company.

The website was designed to:

- clearly present printing services
- showcase company capabilities
- improve brand credibility
- provide a modern customer-facing experience
- make business information easier to access
- create a stronger foundation for online enquiries and future digital marketing

---

# 💡 Solution

The website was developed as a modern responsive frontend using **Next.js, React, TypeScript, Tailwind CSS, and Framer Motion**.

The focus was on creating a clean and professional corporate experience with:

- responsive layouts
- clear service presentation
- modern typography
- smooth animations
- structured content hierarchy
- polished business-focused UI

---

# ✨ Key Features

## 🏢 Corporate Business Presentation

The website provides a professional digital representation of the ColorPlus brand.

Business information is organized clearly so visitors can quickly understand the company and its capabilities.

---

## 🖨️ Service Showcase

The website presents the company's printing-related services in an easy-to-understand format.

This helps potential customers identify the services relevant to their requirements.

---

## 📱 Responsive Design

The interface is designed to work across:

- desktop
- tablet
- mobile devices

Layouts adapt across different screen sizes to maintain readability and usability.

---

## 🎨 Modern UI

The website uses a modern visual system with:

- structured layouts
- clean typography
- strong spacing
- contemporary business styling
- polished visual hierarchy

---

## ✨ Smooth Interactions

Framer Motion is used to create subtle animations and transitions across the website.

These interactions help create a more polished user experience without distracting from the business content.

---

## 🧭 Navigation

The website includes structured navigation to help users move between important areas of the business website efficiently.

# 🚀 Running Locally

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# 📦 Production Build

Create a production build using:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
